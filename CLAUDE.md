## Active Project Overview

**Master's thesis:** Reasoning-rationale distillation for low-label Entity Resolution / Entity Matching.

**Current research question:**
> Can validated, structured, attribute-grounded rationales generated by a reasoning LLM improve label efficiency when distilled into compact seq2seq ER models?

**Active plan:**
`../plans/260619-reasoning-rationale-distillation/plan.md`

**Status:** Pivoted away from the older directions:
- Wikidata multilingual name matching
- mBART generation
- FEBRL clean-data accuracy comparison
- FEBRL adversarial-noise robustness as the main thesis story

Clean FEBRL baselines saturated earlier, so FEBRL alone must not be used as the main proof of the new thesis.

## Tech Stack

- Language: Python 3.13
- ML: PyTorch, HuggingFace Transformers
- Data: pandas, datasets
- Validation: Pydantic v2
- Experiment target: mT5-small first, mT5-base optional after pilot signal
- Teacher: reasoning LLM used offline for rationale generation

## New Target Architecture

```text
raw ER dataset
  -> dataset serializer
  -> low-label sampler
  -> teacher rationale generator
  -> rationale validator/cache
  -> training-target builder
  -> mT5 student training
  -> low-label evaluation runner
  -> label-efficiency plots and thesis tables
```

Teacher LLM is used during training-data creation only. Final inference should use the compact student model without calling the teacher.

## Conventions

- File naming: `snake_case.py`
- Schemas: Pydantic `BaseModel` with explicit fields
- Reproducibility: explicit `seed` parameters, default 42
- Evaluation: train/validation/test split, no test leakage into teacher rationale generation
- Metrics: precision, recall, F1, accuracy, invalid-output rate
- Keep files focused; split large modules when they grow beyond a single responsibility
